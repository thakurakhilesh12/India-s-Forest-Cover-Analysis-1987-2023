# 🌳 India Forest Cover Dashboard — Power BI
The India Forest Cover Dashboard is an interactive Power BI project designed to analyze forest-cover information from the Forest Survey of India. The dashboard combines historical national-level analysis from 1987–2023 with State and Union Territory analysis for 2023. 


## 📊 Project Overview

The **India Forest Cover Dashboard** is an interactive **Microsoft Power BI** project designed to analyze India's forest-cover data from the **Forest Survey of India (FSI)**.

The dashboard combines **historical national-level analysis from 1987 to 2023** with detailed **State and Union Territory analysis for 2023**.

The goal is to transform complex forest-cover data into clear, interactive, and easy-to-understand visual insights.

---

## 🎯 Objectives

* Analyze changes in India's forest cover over time.
* Compare forest cover across States and Union Territories.
* Understand the composition of forest density in 2023.
* Create interactive visualizations from raw forest-cover data.
* Present analytical insights through an easy-to-use Power BI dashboard.

---

## 📑 Dashboard Pages

### 1. National Historical Trend

Shows India's forest-cover trend from **1987 to 2023**.

Key elements include:

* KPI indicators
* Forest-cover percentage
* Forest-cover change compared with the baseline year
* Historical trend visualization
* Assessment-year information

### 2. State Comparison

Provides a **2023 State and Union Territory comparison** using:

* Geographical area
* Forest-cover area
* Forest-cover percentage

This page allows users to explore differences in forest resources across regions.

### 3. Forest Density Composition

Analyzes the composition of forest-related areas in 2023 using:

* 🌲 Very Dense Forest
* 🌳 Moderately Dense Forest
* 🌿 Open Forest
* Scrub

The page also provides state-wise comparisons of these categories.

## 📚 Data Source

The project uses FSI forest-cover assessment data for the historical and 2023 analyses.

---

## 💡 Key Insights

The dashboard provides three levels of analysis:

1. **Historical perspective** — India's forest-cover trend from 1987–2023.
2. **Regional perspective** — comparison of States and Union Territories in 2023.
3. **Density perspective** — breakdown of forest-related areas into different density categories.
